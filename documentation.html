1. Problem Statement

Synthetic and manipulated media — deepfake video, cloned audio, AI-generated text, and doctored images — is now cheap to produce and hard to detect with the naked eye. Misinformation built from this content spreads faster than it can be fact-checked, and it undermines trust in news, evidence, and everyday communication.

At the same time, most “verification” or “detection” tools on the market ask users to trade away their privacy for the service: they require account sign-up, store the uploaded media, log user identity, or lock real functionality behind a paid subscription. For a tool whose entire purpose is trust, this is a contradiction — people are asked to hand over personal data to a service that has no proven track record of protecting it.

The gap in the market is a content-authenticity checker that people can trust precisely because it does not behave like the misinformation ecosystem it is trying to fix.

2. Our Solution

Clarifake is a web platform that lets anyone check whether a piece of digital content — video, audio, text, or image — shows signs of synthetic generation or manipulation, and helps establish whether the information it presents is authentic. The content is processed entirely for the purpose of generating that verdict; it is analyzed on the fly and is not stored, profiled, sold, or tied back to an identifiable user.

The product is built around a single ideological commitment: verification without surveillance. A user should not have to trust us with their data in order for us to help them decide whether to trust someone else's.

3. Core Principles

No data collection: uploaded media is processed in memory / in a transient pipeline for the analysis request only, and is not retained, logged with personal identifiers, or used to build a profile of the user.

No hidden transmission: content is not silently forwarded to third parties beyond the specific analysis APIs required to produce a verdict, and users are told exactly which checks ran.

No subscription paywall: core verification functionality is free and available without an account, so that authenticity-checking is never gated behind payment during a fast-moving misinformation event.

Explainable results: every score is broken down into the individual signals that produced it, rather than being handed to the user as an opaque black-box number.

Session-only processing: results are generated per request; nothing is needed from a prior visit for the tool to work again.

4. How It Works

4.1 Three-Step Flow

Upload media: the user drops in a video, audio file, image, or text snippet, or pastes a link. Frames, waveforms, and available metadata are extracted automatically.

Analyze signals: several independent checks run in parallel to look for generation artifacts — spectral noise, lip-sync drift, unnatural blinking, unnatural phrasing patterns, and more.

Get a verdict: the signals are combined into a single confidence score (0–100) with a clear verdict — authentic, likely synthetic, or inconclusive — plus the evidence behind it.

4.2 The Four Signal Checks

Rather than a single black-box guess, every score is built from independent, individually-displayed checks:

Spectral & pixel analysis — frequency patterns inconsistent with natural camera capture

Temporal analysis — frame-to-frame flicker, warping, and motion drift

Audio-visual synchronization — mismatches between speech and lip / facial movement

Source & metadata analysis — encoding history, content-provenance credentials (e.g. C2PA), and file history

Scores above ~85 are flagged high-confidence synthetic; scores in the 40–85 band are returned as “inconclusive” rather than forced into a false-certain answer.

8. System Approach (Privacy-First Architecture)

Ephemeral processing: uploaded content lives only in memory / temporary storage for the duration of the analysis request, then is discarded immediately after the verdict is returned.

No user accounts required: the core flow needs no login, so there is no persistent user identity to link content to.

Minimal, purpose-only API calls: third-party analysis APIs are called only with the specific data each check needs, not the full user context.

Transparent by design: the results screen shows exactly which checks ran and what each contributed to the final score, so the process itself is auditable by the user.

No monetization via data: with no subscription and no data resale, the project's incentives are aligned with user trust rather than engagement or data harvesting.

9. Differentiators

Most existing detection tools compete on accuracy alone. Clarifake competes on accuracy and trustworthiness of the tool itself:

Free, account-free core functionality — no subscription wall on essential checks

No data collection or retention of uploaded content

Multi-signal, explainable scoring rather than a single opaque output

Designed for both everyday users and professional/newsroom workflows

10. Future Scope

Browser extension for in-place verification of media on social platforms

Real-time livestream authenticity flagging

Source detection via reverse-search APIs: in addition to the existing metadata/C2PA provenance check, we are also working on identifying the origin of uploaded content by cross-referencing it — via API — against reverse-image and reverse-video search engines (e.g. Google Images, Yandex, TinEye, and others). This surfaces where else the video or image already exists online, and helps establish whether the specific footage or frame patterns in the upload have been reused, re-edited, or previously published elsewhere — the search is performed on the content itself, independent of any user identity, and results are not stored beyond the session.

Optional, opt-in API for platforms to integrate automated flagging (still no retention of end-user content)

Expanded language support for text-authenticity checks

Community-reviewed dataset of known synthetic media to keep detection models current

11. Conclusion

Clarifake is proposed as a hackathon solution to the growing problem of synthetic and manipulated digital content, built around a simple idea: a tool that helps people verify what's real should not itself ask them to give up their privacy, and should not put essential trust-and-safety functionality behind a paywall. By combining multi-signal forensic analysis with a strictly no-data-retention, no-subscription approach, Clarifake aims to be a tool people can use with confidence — both in its results and in its handling of their content.
